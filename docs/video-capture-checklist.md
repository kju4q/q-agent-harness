## Recording settings

- Record only a selected portion of the screen
- Use the same window size for all captures
- Increase editor font size
- Hide distractions and sidebars you do not need
- Move the cursor slowly and intentionally

## Best recording order

1. Static screenshots first
2. Repo scroll clips second
3. Terminal/test clips third
4. Final summary screen last
