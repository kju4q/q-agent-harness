# starter

The empty five file harness from the video, ready to drop into any project.

1. Copy this folder's files into your project root, or merge `CLAUDE.md` into the one you already have.
2. Fill in `me.md`.
3. Leave `feedback.md` empty.
4. Run one task.
5. After every session, add one sentence to the file that failed you.

You don't edit these files by hand, you tell the agent "add this to your rules" and it writes the sentence itself.
