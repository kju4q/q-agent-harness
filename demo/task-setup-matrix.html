q-agent-harness

You cannot use the same agent setup for every task.

Debugging needs hypotheses. Research needs sources. Decisions need criteria. The model can stay the same while the structure around the work changes.

Debugging

Find what is wrong

What fails

The agent grabs the first plausible explanation and starts changing code too early.

Better setup
  • form 3 hypotheses
  • check logs and tests
  • rule them out one by one
Research

Figure out what is true

What fails

The agent summarizes one source smoothly and hides disagreement or uncertainty.

Better setup
  • bring back multiple sources
  • compare agreements
  • surface disagreements clearly
Decision

Choose between options

What fails

The agent optimizes for what sounds impressive instead of what fits the actual goal.

Better setup
  • define criteria up front
  • score tradeoffs explicitly
  • name the downside of the recommendation
